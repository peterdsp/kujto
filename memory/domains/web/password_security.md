## Shqip

### Kerkesat per password

- Minimumi 8 karaktere (12+ i rekomanduar).
- Pa maksimum (ose shume i larte, psh 128).
- Lejo te gjitha karakteret, perfshire special chars.
- Mos kerkojme tipe specifike karakteresh (lere perdoruesin te zgjedhe password te forte).

### Storage

- Perdor Argon2id, bcrypt, ose scrypt.
- Asnjehere MD5, SHA1, ose plain SHA256.

---

## English

### Password requirements

- Minimum 8 characters (12+ recommended).
- No maximum (or very high, e.g. 128 chars).
- Allow all characters including special chars.
- Do not require specific character types (let users choose strong passwords).

### Storage

- Use Argon2id, bcrypt, or scrypt.
- Never MD5, SHA1, or plain SHA256.
