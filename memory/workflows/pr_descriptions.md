# Pershkrim PR / PR descriptions

[🇦🇱 Shqip](#shqip) · [🇬🇧 English](#english)

---

## Shqip

### Template minimale

```markdown
## Cfare ndryshon
<1-3 bullet, pse e jo si>

## Konteksti
<link Jira/Issue, screenshot nese ka UI>

## Si u testua
<commands ose hapa konkrete>

## Rrezik
<low/medium/high + arsye e shkurter>
```

### Rregulla
- Subject i PR-it nen 72 karaktere, ne kohen e tashme imperative.
- Pa mure teksti AI. Nese e shkroi AI, edito.
- Pa "ky PR refactor + feature + fix". Nje qellim per PR.
- Linke te klikueshme per Jira, Figma, dokumente, jo ID te zhveshura.

### Pa
- Pa "this PR" ne fillim te cdo bullet.
- Pa lista premtimesh ("makes the code more robust").
- Pa screenshot pa rrethime ne pjesen qe ka ndryshuar.

---

## English

### Minimal template

```markdown
## What changes
<1-3 bullets, why not how>

## Context
<Jira/Issue link, screenshot if UI>

## How it was tested
<concrete commands or steps>

## Risk
<low/medium/high + short reason>
```

### Rules
- PR subject under 72 chars, in imperative present.
- No AI walls of text. If AI wrote it, edit it.
- No "this PR refactors + adds feature + fixes". One purpose per PR.
- Clickable links for Jira, Figma, documents, not bare IDs.

### Avoid
- No "this PR" at the start of every bullet.
- No promise lists ("makes the code more robust").
- No screenshots without highlighting what changed.
