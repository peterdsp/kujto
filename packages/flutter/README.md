# Kujto

Kujto is a tooling CLI for wiring AI memory into Flutter and Dart
repositories.

It creates an `AGENTS.md` marker and can prepare a `memory/` folder for teams
that want the full Kujto memory workflow.

## Usage

```bash
dart run kujto:kujto wire --memory
```

This package is not a Flutter runtime dependency. Do not import it from app
code.
