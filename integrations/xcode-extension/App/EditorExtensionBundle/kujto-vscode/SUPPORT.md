# Support

Use GitHub issues for Kujto Studio VS Code and Cursor extension support:

https://github.com/peterdsp/kujto/issues

Include:

- VS Code or Cursor version.
- Kujto extension version.
- `kujto --version` output, if available.
- The command you ran.
- The Output panel lines from the `Kujto` channel.
- Whether `kujto` is on `PATH` or configured through `kujto.binaryPath`.

Do not paste secrets, private repo contents, production logs, tokens, or
customer data into public issues.
