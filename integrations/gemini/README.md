## Shqip

`install.sh` lidh `AGENTS.md` te `~/.gemini/GEMINI.md`. Gemini CLI lexon `GEMINI.md` globalisht dhe ne repo.

```bash
~/kujto/install.sh
```

Per repo:

```bash
cd path/to/your/repo
~/kujto/bin/sync/wire.sh
```

Gemini CLI mban edhe skill systems te ndara. Kujto fokusohet ne rregullat tekstuale, jo ne ekzekutim te veglave. Veglat e Gemini-t funksionojne paralelisht.

---

## English

`install.sh` symlinks `AGENTS.md` to `~/.gemini/GEMINI.md`. Gemini CLI reads `GEMINI.md` globally and in repos.

```bash
~/kujto/install.sh
```

For a repo:

```bash
cd path/to/your/repo
~/kujto/bin/sync/wire.sh
```

Gemini CLI also has its own skill systems. Kujto focuses on textual rules, not tool execution. Gemini's tools run in parallel.
