Το Kujto Studio είναι μια εφαρμογή Mac local-first που διαβάζει τη μνήμη του repo σας και μετά εμφανίζει τους κανόνες που ισχύουν προτού αγγίξετε ένα αρχείο. Αρχιτεκτονική, κίνδυνοι, σχετικά τεστ, το context του πράκτορα προς εισαγωγή, όλα σε ένα πάνελ.

Το προϊόν

Πριν αγγίξετε αυτό το αρχείο.

Κάθε repo έχει κρυφούς κανόνες. Οι νέοι πράκτορες τους ξεχνούν. Οι νέοι προγραμματιστές τους προσπερνούν. Οι παλιές αποφάσεις ζουν σε PR, README, νήματα στο Slack, στο AGENTS.md και σε δεκάδες διάσπαρτα έγγραφα. Το Kujto Studio κάνει αυτό το χάος ορατό ακριβώς τη στιγμή που το χρειάζεστε.

Κανόνες ανά αρχείο

Οι κανόνες μνήμης φέρουν globs applies_to και ετικέτες κινδύνου. Επιλέξτε ένα αρχείο και δείτε τους κανόνες αρχιτεκτονικής που το διέπουν, ταξινομημένους κατά εξειδίκευση.

Ετυμηγορία εμπιστοσύνης

Ασφαλές, χρειάζεται context ή ζώνη κινδύνου. Μία μόνο ένδειξη σας λέει αν το αρχείο είναι ήρεμο έδαφος ή ένα σημείο που ένας νέος πράκτορας θα χαλάσει αθόρυβα.

Linter μνήμης

Εντοπίζει ξεπερασμένους κανόνες, σπασμένους συνδέσμους και αρχεία διακυβέρνησης που λείπουν, προτού σας κοστίσουν ένα pull request. Ντετερμινιστικό, χωρίς AI.

Εισαγωγέας context για τον πράκτορα

Με ένα κλικ μετατρέπει τους κανόνες του τρέχοντος αρχείου σε ένα μπλοκ prompt που μπορείτε να επικολλήσετε στο Claude, στο Codex, στο Cursor ή σε οποιονδήποτε editor με πράκτορα.

Σύνδεση πολλαπλών πρακτόρων

Μία μόνο πηγή αλήθειας, συνδεδεμένη με symlink σε CLAUDE.md, CODEX.md, GEMINI.md και AGENTS.md. Χωρίς διπλότυπη μνήμη.

Μόνο τοπικά

Το repo σας παραμένει στη συσκευή σας. Τίποτα δεν ανεβαίνει. Η μνήμη είναι Markdown μέσα στο repo σας, με έλεγχο εκδόσεων στο git, ελεγμένη όπως κάθε άλλη αλλαγή.

Πού ζει

Μία μηχανή, πέντε επιφάνειες.

Το ίδιο ευρετήριο μνήμης τροφοδοτεί την εφαρμογή Mac, μια επέκταση Xcode Source Editor, μια επέκταση VS Code ή Cursor, έναν βοηθό στη γραμμή μενού με Shortcuts, και το CLI kujto. Χρησιμοποιήστε ένα, χρησιμοποιήστε τα όλα.

Πλάνο ανάπτυξης

Τι κυκλοφόρησε ήδη, και τι ακολουθεί.

Η εφαρμογή Mac, και οι δύο επεκτάσεις editor, ο βοηθός στη γραμμή μενού και τα App Intents είναι ενεργά στην v1. Να τι βρίσκεται στη σειρά μετά την κυκλοφορία.

Γράφος reducer TCA

Ένα πέρασμα SwiftSyntax που χαρτογραφεί reducers, state, actions και dependency clients σε έναν επιθεωρήσιμο γράφο.

Ευρετηρίαση με Spotlight

Αναζητήστε τη μνήμη και τους κανόνες του repo σας απευθείας από το Spotlight, εκτός σύνδεσης.

Πρότυπα μνήμης για ομάδες

Μοιραστείτε και εκδώστε συμβάσεις σε μια ομάδα χωρίς να διπλασιάζετε αρχεία μνήμης.

Deep links για Cursor / Copilot

Ένα κλικ για να ανοίξετε το τρέχον σύνολο κανόνων μέσα σε μια συνομιλία πράκτορα, προφορτωμένη με το context του αρχείου.

Βελτιώσεις του παρακολουθητή repo

Άμεση επανευρετηρίαση στις αλλαγές του memory/ με ενημερώσεις κάτω του δευτερολέπτου στην πλαϊνή μπάρα.

Τοπικοποίηση

Μεταφορά της διεπαφής στα αλβανικά, γαλλικά, γερμανικά και ισπανικά μέσω του String Catalog.
