The product

Before you touch this file.

Every repo has hidden rules. New agents forget them. New developers miss them. Old decisions live in PRs, READMEs, Slack threads, AGENTS.md, and a dozen scattered docs. Kujto Studio makes that mess visible in the moment you need it.

File-scoped rules

Memory rules carry applies_to globs and risk tags. Select a file, see the architecture rules that govern it, ranked by specificity.

Confidence verdict

Safe, needs context, or danger zone. A single badge tells you whether the file is calm ground or a place a fresh agent will quietly break.

Memory linter

Catches stale rules, broken links, and missing governance files before they cost you a pull request. Deterministic, no AI.

Agent context injector

One click renders the rules for the current file as a prompt block you can paste into Claude, Codex, Cursor, or any editor with an agent.

Multi-agent wire

One source of truth, symlinked into CLAUDE.md, CODEX.md, GEMINI.md, and AGENTS.md. No duplicated memory.

Local only

Your repo stays on your machine. Nothing is uploaded. Memory is Markdown in your repo, versioned in git, reviewed like any other change.
