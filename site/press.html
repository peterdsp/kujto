About

A local memory layer for AI coding agents.

Kujto Studio is a local-first Mac app that reads a codebase's memory and surfaces the rules that apply to a file before it is edited. Architecture guidance, risk tags, related tests, and the exact context to hand to an AI agent land in a single inspector, with a confidence verdict that runs from safe to danger zone. The same engine ships as a standalone SwiftUI app, an Xcode Source Editor extension, a VS Code and Cursor extension, and an open-source command-line tool.

The project was started by Petros Dhespollari, an engineer working between Athens and Tirana, after one too many mornings spent re-explaining the same architecture to a fresh AI agent. The memory framework and CLI are open source under the MIT license. The Mac app is distributed on the Mac App Store and directly on Ko-fi as a Pro build with Sparkle auto-update. All indexing happens on the developer's machine; nothing is uploaded.
